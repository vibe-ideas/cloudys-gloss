开始之前，
你可能想知道。

需要另外启动模型吗？

需要。安装包不包含模型权重。你可以通过项目提供的脚本启动 mlx-serve，或在设置中连接 Ollama / OpenAI-compatible API。查看完整安装指南。

翻译时会上传我的网页吗？

本地模型模式将待翻译文字发送给你配置的本机服务。使用远程 API 时，文字会发送给该 API 提供方。产品页演示只使用预置内容，不会调用模型。

PDF 也可以读吗？

可以使用插件内置 PDF 阅读器打开文件或链接，对照原文和译文，并按段重试。当前主要支持带可提取文字的 PDF；扫描件不具备通用 OCR 翻译能力。

Firefox 为什么需要手动安装一次？

0.1.9 及以前的安装包没有更新地址。覆盖安装含更新地址的新 XPI 后，永久安装的插件可以由 Firefox 检查更新。请在附加组件管理器保持自动更新开启；临时载入的开发扩展不走这条更新流程。
