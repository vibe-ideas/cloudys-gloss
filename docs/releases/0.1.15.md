# Cloudy’s Gloss 0.1.15

修复部分网页段落反复重试仍失败的问题：当批量响应未翻成中文时，单段补译改用明确的中文任务指令，避免重复返回润色后的英文。

- 兼容单段译文的 `translation` / 单项 `translations` JSON 包装，仍拒绝错配和无效译文。
- 区分英文复述、空响应、输出截断和格式错误，便于判断失败原因。
- 保持只补译失败段落、缓存绕过、取消与总超时机制。
- 新增长段落固定回归用例、Chrome / Firefox 网页重试测试及真实 MLX 实验记录。

本机使用截图原段落：修复前 2 次均失败，修复后 5 次均返回中文；每轮仍为 2 次请求。该结果仅验证这条复现路径，模型仍有术语和漏译问题，不代表所有段落的翻译质量保证。详见 [实测报告](../performance/2026-10-21-paragraph-retry.md)。

发布前本地已通过 lint、TypeScript、543 条单元测试，以及双浏览器共 18 条网页 / PDF 重试测试。发布工作流另执行完整双浏览器测试与安装包校验。

Firefox Developer Edition 的永久安装版本可通过原生更新源获取此次更新；临时加载的扩展需要重新加载。
