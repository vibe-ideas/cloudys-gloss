# v0.1.12

## YouTube 双语字幕

- 提前读取字幕并按播放位置缓冲翻译；复用播放器已取得的字幕，减少重复请求。
- 优先处理当前句和临近字幕，隔离批次内的失败，并自动重试暂时性错误。
- 新增右侧双语字幕记录，支持点击时间跳转、补译和查看错误原因。
- 支持拖动边缘或使用键盘调整字幕记录宽度；同一视频内关闭再打开保留宽度。
- 修复记录列表显示“跟随当前句”却没有滚动的问题。字幕换句、窗口缩放和侧栏调宽后继续定位当前句，手动回看时暂停跟随，可一键恢复。
- 优化字幕排版与播放器控件，并隔离网页样式干扰。
- 修复 YouTube Trusted Types 限制导致字幕桥接脚本报错的问题。

## 阅读与设置

- 自动整理中文译文中的中英文、数字间距。
- 翻译为中文时跳过已经是中文的正文，减少不必要的模型请求。
- 设置页改为独立标签页，增加分区导航。
- 产品页采用新的深色单色视觉设计。

## 安装与验证

安装包由 GitHub CI 在 lint、类型检查、单元测试、Chrome / Firefox E2E 和产品页测试通过后生成，并校验 manifest 与 SHA-256。浏览器测试使用模拟模型；实际翻译速度仍取决于模型和可用字幕，不承诺所有视频及模型都能实时完成。

- Chrome：下载 ZIP，解压后加载扩展。已有本地解压安装需要更新文件并重新加载扩展，随后刷新视频页。
- Firefox Developer Edition：永久安装且已允许未签名扩展的用户可通过内置更新地址获取新版本；临时载入不支持该更新方式。本次仍为未签名包。

详见 [发布与安装说明](../development/releases.md)、[YouTube 使用指南](../guides/youtube-subtitles.md) 和 [字幕验证记录](../performance/2026-10-18-youtube-subtitles.md)。
