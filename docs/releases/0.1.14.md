# v0.1.14

v0.1.13 的发布流程已取消，未生成公开 Release。此次同步了字典优先显示后的既有 E2E 预期，保留原有音标、队列隔离、位置稳定和模型补充断言。

## 双语阅读

- 修复 X 文章位于虚拟列表时，正文译文被误藏进虚线悬浮提示的问题；补充文章标题与 ARIA 标题识别。
- 保留真实固定浮层的布局保护，补充桌面、窄屏、异步段落、后续评论防重叠和关闭恢复测试。
- X 适配已通过受控 Chrome／Firefox 布局回归；用户提供的实际文章因浏览器连接超时尚未完成线上验收，详见 [验证记录](../design/2026-10-21-x-article.md)。

## 划词词卡与发音

- 优先显示本地字典释义，再补充 AI 上下文解释与例句；模型出错或超时时保留已经查到的字典内容。
- 内置 57,932 条 ECDICT 释义，按需加载分片并限制内存缓存，查询不占用模型队列。
- AI 词卡请求加入包含排队时间的总超时与取消处理，避免长时间卡在等待状态。
- 英语发音优先选择对应 US／UK 口音的女声；没有合适女声时回退到可用的系统语音。
- 若使用 macOS 本地发音助手，还需在项目中运行 `pnpm model:bridge` 更新助手；浏览器自动更新不会替换本地助手。

## 更新方式

永久安装的 Firefox Developer Edition 扩展（0.1.10 起且自动更新开启）通过 GitHub Release 的 HTTPS 更新清单获取此版本。发布后可在 `about:addons` 的齿轮菜单中选择“检查更新”，无需卸载扩展，已有设置保留。临时载入不适用此更新方式；本次 XPI 仍未签名。

Chrome 本地解压安装需要下载新版 ZIP、更新原目录并重新加载扩展。更新后刷新已打开的网页。

发布由 CI 执行 lint、类型检查、单测、双浏览器 E2E、产品页测试及安装包校验；模拟模型测试不代表真实模型的翻译质量或延迟验收。
