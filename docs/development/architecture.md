# 架构

## 架构

```text
网页内容脚本 / Preact Shadow DOM 词卡
                 │ runtime messaging / Port 分段回传
                 ▼
WXT background → 输入 Zod 校验 → IndexedDB cache
                 │ cache miss
                 ▼
全局并发队列 → OpenAICompatibleProvider → 本地服务 / 兼容 API
                 │ 输出 Zod 校验
                 └─ 结果缓存 → 页面按原位置插入译文
```

- **语义块**：正文按段落、标题、列表项、表格单元格提取；导航、面包屑、按钮、标签页、摘要和静态表单标签按组件提取，不合并整条工具栏。保留内联强调和链接。排除代码、输入值、下拉选项、可编辑区域、`translate="no"`、隐藏标记和扩展自身 DOM。
- **视口调度**：IntersectionObserver 提前 500px 观察；屏幕内段落优先于预取区域；正文每批最多 2 段，短组件最多 8 项，每批不超过 1,800 字符，长段按 900 字符切分，每页最多两个在途批次。可见正文先启动，随后交替处理正文和组件，避免密集导航占满队列。后台通过 runtime Port 在每个完整译文字符串生成后立即推送，长段完成的连续片段也先显示，不等同批或整段结束。短词卡只请求相关词义与一个例句。
- **逐段反馈**：视口附近的语义块显示等待／翻译中；已生成部分可先阅读，批次校验通过后取消加载标记。缓存命中先显示，单段失败可就地重试。
- **大页面扫描**：DOM 游标与语义文字读取共同按每片最多 200 步或 6ms 分片，让首屏发现后立即开始翻译；大容器读取可挂起，先继续发现子块。游标保存后继，SPA 删除当前位置时仍能扫描存活兄弟。调度只遍历视口附近集合；进度更新在 24ms 窗口内合并 DOM 写入，不逐 token 测量布局。
- **增量更新**：MutationObserver 合并 24ms 内的局部变动；原文变化使旧译文失效。菜单、标签页和折叠区展开时局部处理；段落内部 CSS 显隐在下一次统一读取时比较可见文字后重译。普通主题 class/style 变化不会重新扫描整个页面。
- **取消**：关闭翻译、关闭词卡、页面离开和标签关闭时取消任务；快速滚动到远处时取消全部已离开预取区域的批次，让新视口进入队列；队列中的任务也支持取消。以请求代次与原文快照拒绝迟到结果。
- **缓存**：idb / IndexedDB，最多 1,500 条，30 天过期。模型、地址、温度、凭据、文本/上下文均参与哈希键，不跨配置复用。存储不可用时仍可翻译。
- **词卡**：单页面单实例 Shadow DOM；Light / Dark / 系统主题；边缘避让、可滚动、加载态、错误与重试；所有模型字符串通过文本渲染。
- **组件译文**：普通控件在原标签下显示紧凑译文，必要时只放开局部布局；固定、绝对定位和受限吸顶组件保留尺寸，完成后以点状下划线提示，通过悬停、原有键盘焦点或触屏长按显示同一个 Shadow DOM 提示层。保留原有链接、按钮事件和可访问名称，译文作为描述提供。
- **PDF**：独立扩展阅读页按需加载 PDF.js 和本地 worker，打开文件只解析原文；显式开启双语后复用同一 background 队列、流式接口和缓存。文件最大 40 MB；每次只渲染和提取当前页，三个画布合计上限 600 万物理像素，切页、关闭和取消均释放旧工作。几何提取、背景渲染与译文排版分层，普通页同坐标回填，不适合原位排版的几何采用阅读模式，可见性无法验证的绘制保留原稿且不发送提取文字；数值核对失败保留原稿，过长译文可展开。PDF.js 不进入普通网页内容脚本。
- **词典扩展点**：`DictionaryProvider` 接口，可在后台组合本地词典与 LLM。IPA 通过 `PronunciationProvider` 从内置 US / UK 词典精确查询，缺失留空，多读音并列；发音使用浏览器 SpeechSynthesis，优先匹配本地 US / UK 系统语音。

## 代码组织

| 目录 | 职责 |
| --- | --- |
| `entrypoints/` | WXT 入口：background、content、popup、options（设置页组件）、pdf 阅读页 |
| `src/core/` | 设置 Schema、消息、队列、缓存、流式解析、ID 等基础设施 |
| `src/model/` | 模型 Provider、后台翻译服务、本地 MLX 管理与设置页服务卡片 |
| `src/page/` | 网页语义块提取、翻译调度、译文排版与动效、组件提示、输入框翻译 |
| `src/ui/` | 页内 Shadow DOM 界面：悬浮球、词卡，以及由共享色板生成的主题 |
| `src/speech/` | 音标查询与系统发音 |
| `src/pdf/` | PDF 链接识别、读取、几何提取、排版与渲染 |
| `src/dictionaries/` | StarDict 离线词库的导入、存储、查询与设置界面 |
| `src/styles/` | 扩展页面共享样式；`tokens.css` 是所有界面（含 Shadow DOM）的唯一色板 |

依赖方向：`core` 不依赖其他目录；`model`、`page`、`speech`、`pdf`、`dictionaries` 只依赖 `core`（`page` 不依赖 `ui`）；`ui` 与 `entrypoints` 组装上述模块。

全文关闭会移除扩展插入的节点，不重写或替换原文 HTML。SPA 中保留的段落沿用缓存，新增/变化的段落增量处理。第一版不遍历网页自身的 Shadow DOM、iframe 或虚拟化编辑器。

首次划词立即展示浮层与加载态，完整 IPA / 释义在模型返回后展示；缓存命中更快。模型推理耗时取决于本地硬件与服务负载。
