# 数据与权限

图片功能单独限制为离线处理：OCR 模型与 WASM 随包提供；图片文件不发送到模型。识别文字及同图文字语境仅发送到回环地址的本机模型，拒绝远端模型地址，且不自动启动模型下载。不调用浏览器翻译或下载浏览器语言包。在线图片由阅读页向图片原站下载，允许使用该站点已有 Cookie，不向模型传递图片 URL、Cookie 或 Referer；本地图片无需网络。识别文字与坐标最多在本地缓存 48 条、7 天，设置中的清空缓存同时清除此缓存。扩展允许本地 WASM 编译；JavaScript eval 仍被禁止。详见 [图片翻译](../guides/image-translation.md)。

`contextMenus` 用于用户右键后选择正文或图片翻译，不改变浏览器原有菜单；网页只收到与所选操作对应的内部消息。图片链接不传给模型，仍先在扩展内识别。

## 数据与权限

HTTP(S) host permissions 用于网页注入和用户自行配置的模型地址（包括 localhost）。仅 background 发出模型请求，不把 API Key 通过消息传给内容脚本。Key 存储于本机扩展存储，不加密、不云同步；译文与词卡存储于本地 IndexedDB。选区/语义块以及词卡所需的附近上下文会发送到所配置的服务，不包含整个页面 HTML、URL 或页面 Cookie。没有遥测。Firefox manifest 声明 `websiteContent` 传输类别。

实现参考：[WXT 浏览器目标](https://wxt.dev/guide/essentials/target-different-browsers)、[Playwright 扩展测试](https://playwright.dev/docs/chrome-extensions)、[Firefox 数据传输声明](https://extensionworkshop.com/documentation/develop/firefox-builtin-data-consent/)。

`nativeMessaging` 权限用于与用户安装的本地 MLX 助手通信。助手仅允许本扩展 ID，接受固定的状态、启停、重启和自启开关操作；不接受任意命令、模型路径或网页内容。手动管理消息只允许扩展页面发出，网页内容脚本不能直接控制服务。自动启动仅用于用户配置的默认本地 MLX。

词卡优先显示随包 ECDICT 通用英汉释义、用户导入的词库和离线 US / UK 音标，不请求第三方词典服务。点击划词按钮后仍会并行向配置的模型请求语境解释与例句；先显示本地释义不代表关闭 AI 请求。词典来源、许可与覆盖限制见 [离线音标说明](../development/offline-pronunciation.md) 和 [内置词典资产](../../public/dictionaries/README.md)。

PDF 阅读器在扩展标签页中解析用户选择的文件，本地文件本身不会上传。在线 PDF 由阅读器直接下载，不携带 Cookie 或 Referer；这是文件下载，不是模型调用。只有用户点击「开启双语」后，当前页提取的文字才通过 background 发送到所配置的模型，结果使用同一本地缓存。PDF 的解析 worker、字体和字符映射均随包提供；无第三方 CDN。使用远程模型时，待翻译文字会传出本机。

输入框快捷翻译默认开启，可在设置关闭。仅连续短按四下空格后，将当前输入框的全部文本通过 background 发送到用户配置的模型服务；不发送输入框 HTML，也不将草稿和英文译文存入 IndexedDB。密码、验证码、支付卡字段和只读输入框不触发。配置远程 API 时，草稿文字会发送到该服务；取消只能中断尚未完成的请求，不能撤回已经发送的文字。

YouTube 页面启动时会在最多 30 秒内被动观察播放器本来就发起的字幕请求，只暂存当前视频最近一份字幕正文（最多 4 MiB）与公开轨道标签，不保留签名或访问令牌；不发起额外下载，不调用模型，离开视频清空。点击播放器“双语”或“记录”后才开始模型翻译及主动轨道恢复。完整轨道从 YouTube 同源读取，保留播放器自身授权上下文，但不会将字幕链接、Cookie 或访问令牌发送给模型。模型仅收到当前及预取窗口中的字幕文字；译文沿用本地 IndexedDB 缓存。使用远程模型时，这些字幕文字会发送到配置的服务。扩展不下载音视频，不新增分析或遥测。

字幕记录仅保留当前页面内的观看记录，最多 1,000 条，不跨页面持久化；打开侧栏不会额外翻译整片。切换视频、模型或字幕轨道会清空记录。

上述页面启动窗口及 YouTube 字幕开启期间会临时观察当前视频的字幕网络响应，复用播放器已收到的正文。仅匹配字幕 GET 请求；不记录其他请求、请求头或带签名地址，不向额外服务传输。关闭后卸载观察器。
