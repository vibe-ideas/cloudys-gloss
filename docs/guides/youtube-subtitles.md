# YouTube 双语字幕

打开有英文字幕的 YouTube 视频，点击播放器右下方的 **双语** 按钮。原文显示在上方，中文显示在下方；再次点击关闭并恢复原字幕。普通播放页、影院模式、全屏以及 YouTube 嵌入播放器共用这套实现。

字幕翻译使用设置页里当前配置的 MLX、Ollama 或 OpenAI-compatible 模型，无须另设服务。英文字幕可以是作者上传的，也可以是 YouTube 自动生成的。第一版不提供语音识别；视频没有字幕时不会凭空生成字幕，也暂不支持 Shorts 专用播放器或画中画窗口。

## 提前读取不等于已经翻译

开启后优先读取当前视频完整字幕轨道，取得原文和时间轴。当前句先单独请求，随后持续分批翻译后面的字幕，目标是保留约两分钟的中文缓冲，而不是等待整段视频全部翻完。每条译文生成后立即显示；模型请求都由扩展后台发出，沿用并发队列和 IndexedDB 缓存。

快速播放、倍速或刚拖到未翻译的位置时，模型仍可能追不上。暂停视频可以让缓冲继续填充。即使译文尚未生成，原文也会按播放时间正常显示，不会把上一句的中文挂在下一句下面。

把鼠标放在“双语”按钮上，可以看当前模式：

- **字幕轨道 · 提前翻译**：可以预先翻译后文。
- **当前 CC · 实时翻译**：完整轨道读取失败，只能翻译当前显示的字幕；延迟更受模型速度影响。

完整轨道遇到空内容、网络或解析错误时会有限重试，并尝试播放器提供的备用地址。实时模式中，正常换句不会取消正在生成的译文；完成后补入侧栏历史，下一批优先当前句，再补最近缺译的句子。最多保留 4 条、12 秒内的待补字幕，每批最多 3 条，避免模型较慢时积压整段视频。过载时仍可能缺译，可通过侧栏跳转补译。拖动、关闭或切换视频会取消旧请求。

Chrome 自带的“实时字幕”黑色悬浮窗是浏览器语音识别功能，与本插件无关，也不是字幕翻译的必需组件。不需要时，可在 Chrome 设置 → 无障碍中关闭“实时字幕”；插件使用 YouTube 的 CC，不读取该悬浮窗。[Chrome 官方说明](https://support.google.com/chrome/answer/10538231?hl=zh-Hans)

如果没有读到字幕，在 YouTube 的 CC 菜单中选择英文，再点击“重新读取字幕”。批量预翻译失败时保留已确认的译文，其余句子在播放到时各自单独补译一次，避免一条异常连带整批报错。

单句请求失败后会在 0.5 秒、1.5 秒后各自动重试一次；HTTP 429 限流时改为等待 2 秒、4 秒。自动恢复期间保留原文和等待动效，连续失败后才提供“重试这句”和“错误原因”。HTTP 400 / 401 / 403 / 404 / 422 等请求配置错误直接提示，不自动重试。暂停时也能自动恢复；字幕换句、关闭或切换视频后不会由旧计时器继续请求旧句。点击重试会优先请求当前句，不等待无关的预翻译。

若原因显示“模型输出不符合翻译结构要求”，表示返回内容未通过校验，并不代表字幕下载失败。关闭时，仅当扩展曾自动开启 CC，才恢复为关闭；原本开启的 CC 会保留。

## 大视频与右侧字幕记录

点击播放器里的 **记录**，打开双语字幕侧栏；尚未开启双语字幕时会一起开启。普通 YouTube 播放页使用右侧推荐栏的空间，不缩小原播放器。影院、全屏和宽幅嵌入播放器将窄栏放在播放器右侧，视频保留主要宽度。窄窗口改为放在播放器下方，避免遮住画面。点击侧栏右上角 × 只收起记录，字幕翻译继续工作。

中文译文显示在上，英文原文显示在下。点击时间戳跳转到对应句子，并保留原先的播放或暂停状态。侧栏默认跟随当前句；手动滚动、键盘翻阅或查看更早的记录后停止跟随，点击 **回到当前句** 恢复。未完成的历史句可点击 **跳转并补译**，失败句可查看原因并 **跳转并重试**。

记录包含本次观看中已经出现的字幕，不会因为打开侧栏而翻译整片。译文复用同一调度与缓存，迟到的响应也会补入已播放的记录。当前最多保存 1,000 条会话记录，列表每页渲染 40 条，通过“查看更早的字幕 / 查看较新的字幕”浏览。切换视频、切换字幕轨道、修改模型配置或刷新页面会清空相应记录；不保存跨视频的观看历史。

## 安装更新

本地开发构建完成后，Chrome 在 `chrome://extensions` 重新加载 Cloudy’s Gloss，并刷新已有的 YouTube 页签。Firefox 使用对应的 Firefox 构建或本地更新脚本。开发构建的内容更新不会自动改变扩展版本号。
