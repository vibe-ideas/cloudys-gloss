# YouTube 双语字幕

打开有英文字幕的 YouTube 视频，点击播放器右下方的 **双语** 按钮。原文显示在上方，中文显示在下方；再次点击关闭并恢复原字幕。普通播放页、影院模式、全屏以及 YouTube 嵌入播放器共用这套实现。

字幕翻译使用设置页里当前配置的 MLX、Ollama 或 OpenAI-compatible 模型，无须另设服务。英文字幕可以是作者上传的，也可以是 YouTube 自动生成的。第一版不提供语音识别；视频没有字幕时不会凭空生成字幕，也暂不支持 Shorts 专用播放器或画中画窗口。

## 提前读取不等于已经翻译

开启后优先读取当前视频完整字幕轨道，取得原文和时间轴。当前句先单独请求，随后持续分批翻译后面的字幕，目标是保留约两分钟的中文缓冲，而不是等待整段视频全部翻完。每条译文生成后立即显示；模型请求都由扩展后台发出，沿用并发队列和 IndexedDB 缓存。

快速播放、倍速或刚拖到未翻译的位置时，模型仍可能追不上。暂停视频可以让缓冲继续填充。即使译文尚未生成，原文也会按播放时间正常显示，不会把上一句的中文挂在下一句下面。

把鼠标放在“双语”按钮上，可以看当前模式：

- **字幕轨道 · 提前翻译**：可以预先翻译后文。
- **当前 CC · 实时翻译**：完整轨道读取失败，只能翻译当前显示的字幕；延迟更受模型速度影响。

如果没有读到字幕，在 YouTube 的 CC 菜单中选择英文，再点击“重新读取字幕”。批量预翻译失败时保留已确认的译文，其余句子在播放到时各自单独补译一次，避免一条异常连带整批报错。单句请求仍失败时保留原文，并提供“重试这句”和“错误原因”；点击重试会优先请求当前句，不等待无关的预翻译。若原因显示“模型输出不符合翻译结构要求”，表示返回内容未通过校验，并不代表字幕下载失败。关闭时，仅当扩展曾自动开启 CC，才恢复为关闭；原本开启的 CC 会保留。

## 安装更新

本地开发构建完成后，Chrome 在 `chrome://extensions` 重新加载 Cloudy’s Gloss，并刷新已有的 YouTube 页签。Firefox 使用对应的 Firefox 构建或本地更新脚本。开发构建的内容更新不会自动改变扩展版本号。
