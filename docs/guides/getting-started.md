# 安装与使用

## 先启动本地模型

扩展本身不包含模型。Apple Silicon Mac（macOS 26.2+）安装 uv 和 Python 3.12+ 后，在项目目录执行：

```sh
pnpm install
pnpm model:install  # 安装并启动 mlx-serve
pnpm model:bridge   # 注册浏览器启停助手
```

模型准备好后，启动下方的浏览器扩展。服务默认登录 macOS 后自动启动；也可以在扩展设置里关闭登录自启，改为翻译时按需启动。完整安装、迁移、停止和卸载步骤见 [模型启动与登录自启](model-service.md)。其他平台见 [Ollama 与模型配置](models.md)。

## 开发

需要 Node.js 24 或 22.13+，以及 pnpm 10。

```sh
pnpm install
pnpm dev
pnpm dev:firefox
```

WXT 自动打开独立浏览器配置并加载扩展。点击工具栏的 Cloudy’s Gloss →「模型设置」，保存配置并测试连接。打开普通网页后点击右侧「译」悬浮球（或工具栏中的「翻译当前网页」）；再次点击恢复原页面。悬浮球采用紫色云朵标识，默认贴边露出一半，鼠标移近或键盘聚焦时展开，移开后收起；支持拖动换边，旁边的箭头菜单可查看进度、重试、打开模型设置或本页隐藏；位置随窗口大小避让。移近时平滑滑出，轻按有微缩反馈；翻译时显示细进度环和阅读线呼吸动效，完成后静止，后台标签页暂停动画。系统开启减少动态效果时，进度保留静态提示。翻译等待时显示轻量呼吸圆点与占位条，译文逐段淡入；遵循系统减少动态效果设置。选中英文后显示紫色小按钮，点击才请求并展开词卡；仅划词不会调用模型。键盘选词后按 Enter 确认，Escape、取消选区、滚动或点击外部可关闭入口。

浏览器内部页面和扩展商店不支持内容脚本。PDF 使用独立双语阅读器：点击扩展弹窗里的「打开 PDF 文件或链接」，支持本地文件、在线链接和逐页翻译，见 [PDF 使用说明](pdf.md)。安装或更新后，已有网页需要刷新。

词卡 US / UK 按钮提供发音。Firefox + macOS 使用本地助手生成并播放系统语音，以绕开发音结尾的爆音问题；运行 `pnpm model:bridge` 安装或更新助手，发音无需启动模型。其他平台使用浏览器语音，见 [发音与故障排查](pronunciation.md)。

## 网页逐段重试

开启双语后，将鼠标移到正文译文上或聚焦时，只显示小型重翻入口；点击入口或正文译文才展开操作面板，面板不重复展示整段译文。失败段落显示「查看原因与重试」；面板展示该段的 HTTP、连接、超时或输出校验错误，点击「重试这一段」重新请求。已成功的译文也支持「重新翻译这一段」。

页眉、导航、面包屑和按钮等组件同样支持：悬停在原控件上查看译文提示，Alt+Enter 或触屏长按后展开操作，原有点击行为不变。键盘用户可以聚焦正文译文后按 Enter，或聚焦原控件后按 Alt+Enter 进入操作；Esc 关闭并返回原焦点。触屏长按组件可打开面板。

手动重试仅刷新当前段落，绕过旧缓存，保留其他译文。长段落仍分批发送，全部成功后替换旧结果；再次失败保留上次成功译文。单页面只保留一个操作面板，使用 Shadow DOM，不在导航里插入重试按钮，也不会因重试重新扫描整页。所有请求仍由扩展后台发起，与全文翻译共用并发限制。滚动远离、SPA 改写段落、恢复原文或离开页面会取消对应的未完成请求。

## 手动安装生产构建

已在 macOS Firefox 开发者版永久安装本插件的用户，开发完成后运行 `pnpm update:firefox` 即可检查、打包并打开安装提示，见 [本地更新说明](../development/local-firefox-update.md)。

- Chrome/Chromium：`pnpm build`，在 `chrome://extensions` 开发者模式下加载 `.output/chrome-mv3`。
- Firefox 140+：`pnpm build:firefox`，在 `about:debugging#/runtime/this-firefox` 临时载入 `.output/firefox-mv2/manifest.json`。正式分发需 Firefox 签名。
- `pnpm zip` / `pnpm zip:firefox` 生成分发压缩包。

WXT 负责浏览器 API 和 manifest 差异，没有两套业务代码或手写完整 manifest。
