# 导入自己的离线词库

从 **0.1.2** 开始，设置页的「我的离线词库」支持导入 **StarDict**。导入后，在网页选中文字、点击翻译按钮，词卡会先展示本地词库释义，AI 随后补充当前语境和例句。AI 连接失败时，本地释义仍可阅读。

## 如何导入

1. 将下载的 ZIP / TAR / TAR.XZ 包解压到一个文件夹。
2. 打开扩展设置 → **我的离线词库** → **选择词库文件**。
3. 同时选择同一词库、同一文件名前缀的文件：
   - `词库名.ifo`
   - `词库名.idx` 或 `词库名.idx.gz`
   - `词库名.dict`、`词库名.dict.dz` 或 `词库名.dict.gz`
   - 如有 `词库名.syn` / `词库名.syn.gz`，一并选择。
4. 点击 **导入词库**，等待显示词条数量。
5. 在 **试查一个词** 中输入词头，点击 **查询本地词库**，确认释义。

在 macOS 文件选择框中可按住 Command 多选，Windows / Linux 可按住 Ctrl。不要直接选择压缩包、README 或多个词库的文件。`.dict.dz` 和 `.idx.gz` 无需再次手动解压。

没有词库时，可以从 [FreeDict 官方下载页](https://freedict.org/downloads/)选择 English → Chinese 的 **StarDict** 格式。它适合验证导入、一般英汉查词；现代科技覆盖有限，不保证收录产品名与 AI 新术语。[词库选型与实测](../research/2026-10-07-goldendict.md)说明了这些限制。

## 管理与展示

- **停用 / 启用**：保留数据，立即影响后续查询。已经打开的卡片是当次结果，重新划词后更新。
- **删除**：点击删除，再确认；移除这份词库的正文和索引，保留其他词库及内置音标。需要恢复时重新导入。
- **取消导入**：清理未完成数据，原有词库仍可使用。关闭设置页也会取消正在导入的任务；浏览器意外退出后，后台重启会清理半成品。
- **来源**：卡片标注词库名称与原始词头，设置页保留 `.ifo` 的说明和来源文本。词条中的网页、图片、音频和脚本不会加载或运行。
- **大小写**：同一词库中优先精确匹配，例如 `RAG` 与 `rag`。不存在精确形式时可返回不区分大小写的候选，并显示实际词头，具体含义仍需结合语境。
- **读音**：StarDict `t` 字段单独显示为“词库读音（未标注口音）”；不推测 US / UK，也不替换内置音标。发音按钮继续使用现有系统语音。

每份词库最多展示三个匹配词条，总计最多六条；长词条显示前 12,000 字符并给出提示。词库是一般释义参考，不会自动当作正确答案注入模型提示词。

## 第一版的范围与限制

| 项目 | 支持范围 |
| --- | --- |
| 文件版本 | StarDict 2.4.2 / 3.0.0，UTF-8、32 位偏移 |
| 字段 | 纯文本 `m`、读音 `t`、HTML `h`、Pango `g`、XDXF `x`，统一显示为文本 |
| 字段组合 | 支持 `sametypesequence`，以及未设置该选项时的逐字段记录 |
| 别名 | `.syn` / `.syn.gz`，通过索引引用正文 |
| 数量 | 最多五个词库；每库最多 200,000 条正文及 200,000 条别名 |
| 文件大小 | 所选文件合计 ≤ 80 MiB；正文解压后及索引累计引用正文量均 ≤ 64 MiB；单条正文 ≤ 64 KiB；索引 / 别名各 ≤ 16 MiB |
| 暂不支持 | MDX / MDD、DSL、64 位大词库、非 UTF-8 文本、音视频与资源包字段、直接导入 ZIP / TAR |

不支持的格式会明确报错，不会跳过部分词条后把残缺词库显示为导入成功。需要其他格式时，可先使用 [PyGlossary](https://github.com/ilius/pyglossary) 转换为本版支持的 StarDict 文本格式；转换后的内容和数据许可仍由原词库决定。

文件只保存在当前浏览器的扩展 IndexedDB，不上传、不跨浏览器同步。卸载扩展或清除扩展站点数据会丢失导入词库；保留原始文件作为备份。设置页的「清空缓存」仅清除翻译与 AI 词卡缓存，不删除导入词库。用户选中的文本仍按原有设置发送到模型服务。

## 性能与实现

大文件通过设置页与后台共享的 IndexedDB 暂存，不通过 runtime 消息复制整份数据。后台受限解压、每 500 条批量写入并让出执行机会，提供进度与取消；正文和别名全部校验通过后才原子启用。单个后台同一时间只允许一个导入任务。

日常查询使用 IndexedDB 复合键索引，只读取少量匹配记录，不加载整本词库，也不占用模型并发队列。导入阶段会临时持有解压后的文件与批次数据，因此文件大小上限不是进程内存上限。解析器与 HTML 实体解码只进入设置页和后台，网页内容脚本只接收查询结果。
