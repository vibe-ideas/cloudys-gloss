# PDF 双语阅读

点击浏览器工具栏中的 Cloudy’s Gloss，再选择「打开 PDF 文件或链接」。阅读器支持本地文件和 HTTP(S) 链接，每个文件最大 40 MB。打开可识别的在线 PDF 标签页时，弹窗会直接显示「在双语阅读器中打开 PDF」。地址没有 `.pdf` 后缀、未被自动识别时，也可以手动粘贴链接。

浏览器自带 PDF 阅读器不允许普通内容脚本注入，因此双语阅读会在独立扩展标签页中进行，不修改浏览器的原阅读器。参见 [Firefox 内容脚本限制](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/Content_scripts)。

## 阅读与翻译

1. 选择本地 PDF 或打开链接。此时只在本机解析文件，不向模型发送文字。
2. 原始页面显示在左侧，可选择的原文段落显示在右侧；窄窗口中上下排列。
3. 点击「开启双语」，当前页段落通过扩展后台发送到已配置的模型。译文逐段出现，不等待整本文件完成。
4. 使用上一页、下一页或页码跳转。切页会取消上一页尚未完成的请求，继续翻译新页。
5. 「暂停双语」取消未完成请求，保留已经完成的译文；「关闭文件」释放当前文档。更换文件后需重新开启双语。

模型连接、缓存和并发设置与网页翻译共用。模型未启动时，可以从阅读器右上角进入「模型设置」。本地 MLX 助手的按需启动沿用原设置。

## 当前支持范围

- 支持含可提取文字的 PDF，按文字位置合并行和段落；原图始终保留，便于对照。
- 扫描件或无文字页可以看原图，但暂不支持 OCR；阅读器会明确提示，可以继续浏览其他页。
- 密码保护的文件需先在原阅读器中解锁并另存。
- 在线下载不携带页面 Cookie。需要登录的文件请先下载，再选择本地文件打开。
- 多栏论文、复杂表格、公式和特殊字形的提取顺序可能不理想；当前不承诺复制 PDF 的排版结构，也不导出双语 PDF。
- 原始页面用于视觉对照，不提供原生 PDF 的表单填写、批注或链接交互。
- 超大单页最多展示 200 段或 100,000 字符，并显示截断提示；原始页面仍可查看。

## 资源与数据

只有当前页会创建画布并提取文字，画布上限为 300 万像素；不会为整本 PDF 同时创建页面或预先请求所有译文。开启后按批翻译当前页全部已提取段落，密集单页仍可能耗时较长，可暂停或切页取消。300 万像素是画布限制，不代表解析整个 PDF 的内存上限。解析 worker、字体和字符映射随扩展打包，不使用第三方 CDN，也不进入普通网页的内容脚本。

本地文件由浏览器本机解析，文件本身不会上传。开启双语后，当前页提取的文字会发送到你配置的模型服务，译文进入扩展本地缓存。使用远程 API 时，这些文字会离开本机。在线 PDF 会直接向原地址下载，超时、超限或取消后停止读取。

稳定回归用例位于 `tests/e2e/pdf.spec.ts`；下载与文本提取测试位于 `tests/unit/pdf-io.test.ts`、`tests/unit/pdf-text.test.ts`。
