# Apple 产品页真实浏览验收

结论：**部分可用，整体验收未通过**。导航与普通段落的排版比此前改善，但复杂控件、脚注、营销文案和部分请求失败仍会影响阅读。受控 E2E 通过不能替代真实页面验收。

## 环境与范围

- 页面：[iPhone 18 Pro](https://www.apple.com/iphone-18-pro/)，2026-10-05 的实际页面。
- macOS / M4 Pro，Firefox Developer Edition 158.0；插件代码 `3e89988`。
- 沿用本机 mlx-serve 与 Qwen3 1.7B 4bit 配置，未切换模型、清缓存或修改提示词。
- 人工浏览一轮，检查首屏、相机轮播、视频、电池和充电参数、浅色页尾；执行一次轮播下一项、一次失败段落重试和一次关闭翻译。
- 使用已有缓存与新请求混合的实际会话。本轮不统计 TPS、首译延迟、全页完成率或质量通过率；未逐字审核全页，也未在 Chrome 或窄屏重跑此真实页面。

## 翻译质量样例

这些是当前页面上的实际输出，不是人工润色后的译文。

| 原文位置 / 短句 | 当前输出或问题 | 影响 |
| --- | --- | --- |
| Most wanted. | 最 wanted. | 中英文混杂 |
| Such a control freak. | 如此一个控制狂。 | 没有结合相机控制功能理解文案 |
| There’s a new Pro in charge. | 有位新负责人。 | 丢失充电场景与产品含义 |
| 电池大标题后的脚注 4 | 译文出现“4 小时” | 将引用编号变成不存在的续航信息 |
| 升级介绍中的续航比较 | 未保留“多 6 小时”的信息 | 关键比较数字缺失 |

## 修复优先级与验收条件

1. **先处理脚注污染。** 提取时区分引用编号与正文数字；保留原页面脚注链接，不能简单删掉所有上标（公式、单位可能使用上标）。验收时确认脚注不进入模型正文，30/45 小时、6 小时增量、50%、15 分钟等正文数字保持完整。
2. **补齐交互控件边界。** 覆盖单个 CTA、嵌套链接、ARIA tab/tablist 等结构，同时保留正常段落中的文本链接。验收时按钮与标签无多余整段译文，切换交互继续可用。
3. **定位结构错误。** 留存脱敏后的实际请求、响应与校验错误，区分提取、分批映射、模型响应和解析失败，再建立回归；本轮 UI 证据不足以归因到其中某一层。
4. **再优化展示标题和营销文案。** 使用通用的视觉层级规则与独立质量语料，不针对 Apple 文案硬编码译文。大号原文与译文的字号、颜色关系需要重新做视觉验收。

本报告记录待修问题，**不表示上述问题已修复**。对应的自动化 DOM 夹具和质量回归应维护在 `tests/`，不把线上页面作为 CI 的唯一依赖。
