# 全文双语排版

默认保留导航和菜单原样，只为正文添加段下译文；导航文字仍可主动划词。文章页眉、普通列表、正文链接与页脚说明继续翻译。识别依据是 `nav` 与 ARIA navigation/menu/menubar/toolbar，不依赖站点域名。

正文取消统一绿色竖线、左缩进和半透明效果。使用原文容器的颜色与字体、透明背景和 1.75 行高，标题译文缩小；同页浅深区块以及页面切换主题时自然继承颜色。此方案不额外测量布局，也不替网页修复原本就不足的对比度。

仅由多个直接操作链接组成的按钮组不生成整段译文。模型确认返回与原文完全一致的内容时，不再显示重复行；这只减少冗余展示，不代表模型已经完成语义翻译。

加载态只保留轻微呼吸点。文本节点在流式更新时保持挂载，只在第一段文字出现时淡入，减少动态效果偏好继续生效。关闭后移除译文和会话样式。
