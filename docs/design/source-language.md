# 中文正文跳过网页翻译

2026-10-18。旧逻辑虽然排除了完全没有西文字母的中文，但只要一个语义块含 `API`、`Kubernetes` 或英文网址，就会把整个中文段落送给模型。

## 现在的行为

在语义块提取时使用 [轻量文本判断](../../src/core/source-language.ts)，同步扫描、分时扫描、视口附近的可见文本复核使用同一规则：

- 纯中文保留原文；包含少量技术名词、数字、地址的中文正文也跳过。
- 西文为主的正文、纯英文导航标签、中文页面中的英文段落继续翻译。
- 每块单独判断，不根据整页 `lang` 跳过页面。
- 已跳过的中文被 SPA 改成英文后，现有 MutationObserver 会增量发现；已翻译的英文改为中文后移除旧译文。
- 判断发生在注册翻译观察器、创建占位和请求之前。跳过段落不进入翻译缓存或模型队列，不额外扫描整页。

当前规则是启发式：中英混排时按汉字数与西文单词数比较，避免长产品名因字母多而压过中文说明；比较前排除可识别的代码、地址、邮箱和路径。至少四个连续英文单词且包含常见英文功能词的内容仍参与翻译，避免长中文上下文盖过其中的英文句子。假名、谚文不按汉字比例误判为中文。

这不是语言识别模型。极短或特殊混排可能有歧义；测试语料保留在仓库，后续可补充实际反例。本次只影响网页自动全文翻译，不改变 PDF、主动划词查询或四下空格的中文转英文能力。

## 验证与开销

- [判定单测](../../tests/unit/source-language.test.ts)：中文技术正文、繁体中文、邮箱／网址、英文导航、夹中文术语的英文正文、日文混排。
- [语义提取测试](../../tests/unit/blocks.test.ts)：三条提取路径结果一致。
- [生命周期测试](../../tests/unit/translator.test.ts)：跳过中文不注册翻译观察器，中文变英文与英文变中文均按变更区域处理。
- [双浏览器 E2E](../../tests/e2e/reading/source-language.spec.ts)：检查实际请求文本列表与 DOM 原样保留，验证 SPA 切换；相关组件、大页面与排版回归共 14 项通过，完整单测 426 项通过，lint / typecheck 通过。

纯文本判断的测量方法、结果与复现命令见 [段落语言判断性能](../performance/2026-10-18-source-language.md)。
