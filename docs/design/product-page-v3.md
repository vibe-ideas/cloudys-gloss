# 产品页第三版：深黑与冷白

2026-10-14。用户要求参考 [xAI 官网](https://x.ai/) 重构产品页。沿用 Cloudy’s Gloss 名称、折页 G 标记、产品功能与原有 GitHub Pages 地址。

## 视觉与结构

- 首屏采用大字号两行标题、短说明、两个明确入口，配合静态光环与斜向光线。图形用 CSS 绘制，正文保持独立的清晰文字层。
- 深色区负责品牌、演示与模型介绍；冷白区承载实际阅读体验及安装步骤，形成明确的阅读节奏。
- 用细线、编号、留白和横向列表建立秩序，移除旧版倾斜卡片、荧光绿跑马条和大面积圆角底板。
- 绿色集中在品牌标记及少量状态点；紫色保留在词义与译文示例中。视频和分享封面同步适配新页面。
- 页脚使用大字 GLOSS 形成收尾，页面保留完整的安装条件、模型启动指南、隐私说明和常见问题。

## 交互与性能

双语切换支持逐段出现与恢复；快速开关会作废旧计时器的回填。词卡支持点击打开、点击外部关闭、Escape 关闭并恢复焦点。

手机导航可通过键盘展开、通过 Escape 关闭并回到菜单按钮；选中章节自动收起，切换桌面宽度后恢复横向导航。`prefers-reduced-motion` 同时停用首屏入场、译文入场、按钮与导航动效。

首屏无图片下载、无 WebGL、无持续刷新循环。视频使用 `preload="none"`，不自动播放；分享封面只供社交预览使用。仅可选的 GitHub Release 查询会请求外部 API，失败仍可下载。
