# 浏览器按需启动 MLX 实测

日期：2026-10-04。Apple M4 Pro，本地默认 `mlx-community/Qwen2.5-3B-Instruct-4bit`，MLX 0.32.3 / mlx-lm 0.32.0。模型权重已下载，独立环境已安装。每个浏览器完成两次回归，表中是观测范围，不作为稳定性能基线或 TPS 指标。

| 浏览器 | 点击启动到真实生成验证完成 | 服务停止时点击翻译到首段完整中文 |
| --- | ---: | ---: |
| Playwright Chrome for Testing | 6.924–7.906 秒 | 7.851–8.878 秒 |
| Firefox Developer Edition | 7.166–8.184 秒 | 8.333–8.829 秒 |

“服务停止”指 MLX 进程已经退出，权重文件仍可能命中系统磁盘缓存；不包含首次安装、下载，也不代表重启电脑后的耗时。首段计时包含启动、生成预检、实际翻译与 DOM 展示，页面来自本地测试夹具，不访问外部模型。

复现：`pnpm model:bridge` 后运行 `pnpm test:native`。稳定场景在 `tests/live/native-service.spec.ts`，每个浏览器依次验证关闭登录自启、停止、手动启动、再次停止、网页翻译按需启动、中文译文出现，最后恢复原自启偏好。测试单独运行，不加入需要 Apple GPU 的公共 CI。

本次真实测试修复了两处 macOS 集成问题：`bootout` 返回后需要等待旧服务实际卸载；浏览器子进程不重新创建 LaunchAgent 文件，而是在锁保护下更新安装器已建立的配置，避免新文件被浏览器自动标记隔离。没有修改系统安全设置。
