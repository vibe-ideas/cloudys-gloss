# 恢复纯模型翻译与右键操作

浏览器翻译方案已撤回。正文、图片、词卡及输入框均使用各自配置的模型路径；图片仍限制本机回环接口，PaddleOCR/WASM 保留。生产代码不再调用 `Translator.create`，不再下载浏览器语言包，也没有浏览器翻译设置入口。旧浏览器方案的十几秒结果不能当作当前模型速度。

## 调度改动

默认 Qwen3 1.7B 本机预设请求并发为 8；正文页面不再固定最多两批，而是遵守配置的 1–8 并发。高并发时附近预取距离从 500px 增至 1500px，仍不一次提交整篇或整站。每批正文最多两段、1800 字符，保持原文、模型、提示词、中文/JSON 校验和失败补译规则。

升级时，一次性将默认本机模型的旧单并发配置调为 8；自定义模型、远端地址及其他并发保留。迁移带独立版本标记，之后用户手动降低到 1–2 不会被再次覆盖；降低并发可减少内存压力和首段等待。后端是否支持并行、实际吞吐取决于模型服务，扩展并发不代表后端一定并行。

完整扩展实测发现，忙碌的本机服务会使重复 `/models` 探测超过 1.5 秒，随后错误触发本地助手。现在成功的健康检查和真实模型 HTTP 响应会确认服务存活 30 秒，持续推理期间不重复探测；真实连接失败或手动停止/重启会使确认失效。缓存译文不刷新服务状态，用户取消不误报服务掉线。

完整 Chrome 单并发首段 1.47 秒，八并发 3.71 秒；全文约减少 47%，但首段更慢。Firefox 八并发首段 2.36 秒。完整扩展计时包含生产 IPC、调度、语义提取、模型生成、校验、滚动和 DOM 显示，不能用 40.32 秒的协议层数字替代。当前没有达到整篇 30 秒目标。样本数量不足以报告 P95，日常应用仍在运行，不是封闭环境跑分。

中文提示词试验变成 49.50 秒、33 次补译；逐段单发试验为 52.39 秒、13 次补译，均已撤回。保留原模型提示词及每批两段，未以放宽校验或删减原文换取速度。完整扩展最初两轮在第 17 块因健康检查误判失败，修复后才完成；失败轮不算通过。

另在独立回环端口 8087 启动已安装的原生 mlx-serve 26.10.1，复用本地已缓存的 Qwen3 1.7B 权重，不下载模型。八并发协议层 40.57 秒、12 次补译，没有稳定优于原有 Python 服务，因此没有替换用户的 8080 服务或其登录自启配置。临时进程已停止。

**结构完成不是语义准确率。** 抽样比较单并发与八并发，两者均出现 `driver` 被译为“驾驶员”、后台被译为“背景”、`23 of 40` 丢失分母、来源限定误译等问题；八并发样本也有任务编号被译错的情况。没有完成全部文章语义验收，不能宣称当前 1.7B 小模型“快且完全准确”，也不把数字丢失等结果视为质量通过。图片路径另有数字/术语保护，不能将其校验保证推广到正文。

## 右键使用

- 右键网页：选择“Cloudy’s Gloss：翻译网页 / 恢复原文”。
- 右键图片：选择“Cloudy’s Gloss：翻译图片 / 切换原图”。同地址多图优先处理刚才右键的图片；框架图片无法原位处理时打开图片阅读页。
- 右键悬浮球：打开已有的翻译快捷面板，可翻译、恢复原文、打开图片阅读页或设置。

新增 `contextMenus` 权限，仅用于用户选择的菜单操作，不扩大主机访问范围。原生菜单保留浏览器保存图片、复制链接等功能。

## 验证场景

全量 `pnpm check`：ESLint、TypeScript 通过，47 个文件、579 项单元测试通过。最后一轮右键、图片、两种并发的大页面及切后台续译共 18 项 E2E 全部通过，另有两浏览器紧凑布局各 1 项通过。Firefox 测试控制端口与模型端口分离，避免被故意挂起的 HTTP 流占满连接池，影响测试本身的控制命令。没有通过放宽实际页面可见性断言来跳过后台暂停验证。对 `src/` 和 `entrypoints/` 的审计未发现浏览器翻译 API 的调用或 transport 引用。

本轮新增/修改测试的完整名称：

- 模型设置 > 新安装默认连接本地 MLX，使用八并发和 120 秒超时
- 模型设置 > 旧设置即使保存浏览器翻译模式也移除该字段，不能重新开启浏览器语言包
- 浏览器按需启动本地 MLX > 本机模型持续返回 HTTP 响应时不重复探测 models，网络失败或手动停止后重新检查
- 浏览器按需启动本地 MLX > 升级本机默认预设的单并发到八并发，远端接口、自定义模型及其他并发均保留
- 双语阅读生命周期 > 读者配置八并发时附近段落可同时发出八批，改回单并发后不再启动超额请求
- 浏览器原生翻译右键菜单 > 安装或重启浏览器后显示网页和图片操作，并保留浏览器原有菜单
- 浏览器原生翻译右键菜单 > 右键选择翻译网页时只切换当前标签正文，选择图片时在文章中操作当前图
- 浏览器原生翻译右键菜单 > 内嵌框架图片无法原位处理时打开阅读页，脚本或带凭据的图片地址不启动处理
- 右键悬浮球后打开翻译快捷面板，选择翻译和恢复原文各执行一次
- 右键文章内图片后从菜单通道翻译所选图片，重复图片地址不会错误覆盖第一张
- 2000 段页面配置 2 并发时限制在途批次，逐段显示；跳到页尾取消旧任务，关闭恢复原文
- 2000 段页面配置 8 并发时限制在途批次，逐段显示；跳到页尾取消旧任务，关闭恢复原文
- 两千段长网页切出标签后暂停新增翻译，切回后滚动续译且保留已完成段落
