## 指标口径

- **生成 TPS**：每秒生成的 token 数，token 不等于汉字或英文单词。HTTP 流估算包含传输和服务开销，不能冒充模型内部解码计时。
- **首 token 延迟（TTFT）**：发出请求到收到首个非空正文片段。包含提示词处理，但不是第一段译文已可读的时间。
- **首段译文延迟**：首个完整译文字符串被 provider 推送，或浏览器真正显示；每份报告单独注明测量层。
- **完整耗时**：含结构校验与必要的回退/重试。高 TPS 不保证这一项更小。
- **结构成功率**：JSON/Zod 校验通过；不代表音标、词义或翻译正确。少量词条重复测试不能推断广泛准确率。
- **内存**：区分权重文件、进程 physical footprint、包含映射/共享页的 resident，以及峰值。不能拿不同口径横向比较。

数据使用合成公开文本，没有上传网页内容。所有结果只是这台 M4 Pro 的桌面实测，不是跨设备排行榜，也未测能耗或 GUI 应用本身的开销。
